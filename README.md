## 🚀 Featured Projects

### 📚 BookNook – A Small Online Library

An online library platform where readers can discover books, add book listings, borrow available books, and manage their borrowing history.

**Technologies:** Next.js, React, TypeScript, Tailwind CSS, Express.js, MongoDB, Better Auth, JWT.

- 🌐 [Live Demo](https://booknook-frontend-six.vercel.app)
- 💻 [GitHub Repository](https://github.com/NusrathChowdhury/BookNook-Client)

### 🛒 Bazar Dor – Market Price Information Platform

A Bengali-focused platform for exploring essential commodity prices, comparing market rates, and viewing price trends.

**Technologies:** Next.js, React, TypeScript, Tailwind CSS, Better Auth, REST APIs.

- 🌐 [Live Demo](https://bazardor-gamma-blue.vercel.app)
- 💻 [GitHub Repository](https://github.com/NusrathChowdhury/Bazar_Dor)

### 🌱 Bangla CropAssist – Multi-Crop Disease Detection Research

A Bangla-language agricultural assistance project that helps users identify crop diseases from symptom descriptions and explore treatment guidance for rice, potato, and lentil.

**Technologies:** Python, NLP, BanglaBERT, LSTM, Machine Learning, Hugging Face Spaces.

- Dataset containing 73,000+ Bangla agricultural disease descriptions across 34 classes.
- Research contribution in dataset development, curation, and paper preparation.
- 🌐 [Live Demo](https://huggingface.co/spaces/CRop-p/bangla-crop-disease)

## 💻 Run Locally

Follow these steps to run the project on your local machine.

**1. Clone the repository**

```bash
git clone https://github.com/NusrathChowdhury/MyPortfolio.git
```

**2. Navigate to the project directory**

```bash
cd MyPortfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in your browser**

```text
http://localhost:3000
```
